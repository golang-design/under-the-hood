本章讨论 Go 何以形成今天的面貌：它要解决 Google 当时面临的哪些工程问题，三位设计者各自带来了什么，
以及为何宁可少提供一些特性（1.1）；Go 由语言、运行时与工具链三部分组成，各部分做出了哪些与众不同的
决定（1.2）；goroutine 与 channel 背后的思想如何从 1978 年的一篇论文逐步演变为 Go 的设计（1.3）。
